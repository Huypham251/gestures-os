# Gesture OS

A Python application that uses computer vision and hand gesture recognition to control macOS desktops.

## Features

- Detect hand gestures using MediaPipe
- Track hand movement with OpenCV
- Switch macOS desktops using gestures

## Tech Stack

- Python
- OpenCV
- MediaPipe
- pynput

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
